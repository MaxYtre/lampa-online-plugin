# Lampa Online Plugin (MVP)

Плагин для медиацентра [Lampa](http://lampa.mx/), добавляющий возможность онлайн-просмотра фильмов, сериалов и аниме прямо из карточки контента во встроенном плеере Lampa.

---

## 🚀 Возможности

- **Кнопка «Онлайн»** в карточке фильма/сериала рядом со стандартной кнопкой «Торренты».
- **Многосерийные плейлисты**: автоматическое переключение серий во встроенном плеере Lampa (`Lampa.Player.playlist`).
- **Выбор качества**: поддержка адаптивных и фиксированных потоков (1080p, 720p, 480p).
- **История и таймкоды**: интеграция с `Lampa.Timeline` и кэшем просмотренного — просмотренные серии помечаются галочкой `✓`.
- **Полная поддержка ТВ-пультов (D-Pad)**: навигация стрелками на пульте Smart TV, Android TV, webOS и Tizen.

---

## 📺 Поддерживаемые источники

1. **⚡ Collaps (HLS & Multi-Audio)**
   - Прямой стриминг в формате **HLS (.m3u8)** с поддержкой переключения звуковых дорожек прямо в плеере Lampa.
   - Включает популярные студии: **HDRezka Studio**, **Кубик в Кубе**, **TVShows**, **LostFilm**, **Paramount Comedy**, **Дубляж**.
   - Доступны все 28 сезонов «Южного Парка» и огромный каталог зарубежных и отечественных фильмов.

2. **🎞️ Filmix API (v2)**
   - Крупнейшая база фильмов, сериалов и мультсериалов (включая все 28 сезонов «Южного Парка», голливудские новинки и классику).
   - Выбор переводов и студий озвучки (Paramount Comedy, MTV, HDrezka, Дубляж, Ultradox и др.).
   - Поддержка качества от 480p до Full HD и 4K (2160p / HDR).
   - Плейлисты по сезонам с автопереходом к следующей серии.

3. **🎬 Kodik API**
   - Обширная база фильмов, сериалов, дорам и мультфильмов.
   - Выбор студии озвучки (LostFilm, HDRezka, Дублированный, AniDUB, TVShows и др.).
   - Навигация по сезонам и сериям.
   - Автоматическое извлечение m3u8 видеопотока через защищённое декодирование плеера.

4. **🌐 HDRezka (Каталог и зеркала)**
   - Поиск по базе HDRezka с настраиваемым адресом зеркала (по умолчанию `kvk.zone`).
   - Информирование о доступности озвучек HDRezka в источниках Collaps и Filmix без ограничений авторизации.

5. **🎌 AniLibria API**
   - Прямой доступ к релизам и озвучке AniLibria.
   - Поддержка многосерийных релизов с выбором серий.
   - Прямые HLS-потоки без необходимости авторизации.

6. **🔧 Тестовый HLS поток (Direct HLS 1080p/720p/480p)**
   - Моментальная диагностика совместимости встроенного плеера Lampa на вашем ТВ в один клик.

## 📥 Установка в Lampa

### Прямые ссылки на плагин:

* **GitHub Pages**:
  ```text
  https://maxytre.github.io/lampa-online-plugin/plugin.js
  ```
* **jsDelivr CDN (рекомендуется для быстрого доступа с правильными CORS заголовками)**:
  ```text
  https://cdn.jsdelivr.net/gh/MaxYtre/lampa-online-plugin@main/plugin.js
  ```

### Пошаговая инструкция:
1. Запустите приложение **Lampa** на вашем ТВ, приставке или в браузере ([lampa.mx](https://lampa.mx/)).
2. Откройте **Настройки** (иконка шестерёнки в левом меню).
3. Перейдите в раздел **Расширения** (или **Плагины**).
4. Нажмите кнопку **«Добавить плагин»**.
5. В появившемся поле введите одну из ссылок выше:
   `https://cdn.jsdelivr.net/gh/MaxYtre/lampa-online-plugin@main/plugin.js`
6. Подтвердите добавление и **перезагрузите Lampa**.
7. Откройте карточку любого фильма или сериала — появится кнопка **«Онлайн»**.

## 🧪 Автоматическая проверка видеопотоков (Без необходимости открывать ТВ)

В проект встроен автономный инструмент для мгновенной проверки работоспособности плагина и валидации реальных видеопотоков по сети:

### 1. Запуск через Node.js / npm:

```bash
# Полный запуск тестов по всем релизам (South Park, Interstellar, Attack on Titan):
npm test
# или: node test.js

# Быстрая проверка "Южного Парка" (South Park):
npm run test:southpark
# или: node test.js --title "Южный Парк"

# Проверка полнометражного фильма "Интерстеллар":
npm run test:movie

# Проверка конкретного провайдера:
node test.js --provider filmix
node test.js --provider collaps

# Проверка любого произвольного названия:
node test.js --title "Матрица"
```

Инструмент:
- Эмулирует среду Lampa и интерфейс выбора карточки.
- Проходит путь пользователя: поиск -> выбор релиза -> выбор сезона -> выбор озвучки -> серия -> запуск.
- **Глубокая проверка потока по сети**:
  - Для **HLS (.m3u8)**: скачивает мастер-плейлист, валидирует `#EXTM3U`, звуковые дорожки и первый сегмент видео.
  - Для **MP4**: делает `Range: bytes=0-2048` запрос, проверяет заголовок контейнера MP4 (`ftyp`) и замеряет скорость отклика.

### 2. Интерактивный плеер в браузере (`tester.html`):

Вы можете просто открыть файл [`tester.html`](file:///c:/Users/root/project/ForLampa/tester.html) в браузере на ПК или ТВ:
- Введите название фильма/сериала.
- Нажмите кнопку нужного источника (Collaps, Filmix, Kodik).
- Поток мгновенно загрузится во встроенный HTML5 / HLS видеоплеер прямо на странице.
