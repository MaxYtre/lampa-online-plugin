# План реализации MVP онлайн-плагина для Lampa

Создание первого рабочего прототипа (MVP) плагина для медиацентра [Lampa](http://lampa.mx/), который добавит кнопку «Онлайн» в карточку фильма, выполнит поиск видеопотока в работающем источнике, запустит воспроизведение во встроенном плеере Lampa и будет опубликован в вашем репозитории на GitHub с прямой ссылкой для добавления в приложение.

---

## 1. Требуется подтверждение пользователя

> [!IMPORTANT]
> Для тестового запуска (MVP) предлагается следующая конфигурация:
> 1. **Репозиторий**: создать публичный репозиторий `MaxYtre/lampa-online-plugin` (или `ForLampa`) через привязанный аккаунт GitHub CLI (`MaxYtre`).
> 2. **Стартовый рабочий сервис для теста**:
>    * **AniLibria API (публичный API без токенов и без блокировок)** — открытый сервис с честными потоками HLS (`1080p`/`720p`), многосерийным плейлистом и русской озвучкой.
>    * **Тестовый HLS-стрим (Direct HLS 1080p/720p)** — моментальная проверка работы встроенного плеера Lampa на вашем ТВ/браузере в один клик.
>    * **Kodik API интеграция (поиск фильмов и сериалов по названию)** — поиск по базе фильмов/сериалов с публичным токеном вебмастера.
> 3. **Итоговая ссылка**: ссылка GitHub Pages и CDN jsDelivr вида:
>    `https://maxytre.github.io/lampa-online-plugin/plugin.js`

## 3. Детали реализации компонентов

### А. Скрипт плагина (`plugin.js`)
1. **Инициализация**:
   * Ожидание загрузки приложения (`window.appready` или событие `Lampa.Listener.follow('app', ...)`).
   * Регистрация уникального плагина в `Lampa.Plugins.add(...)`.
2. **Встраивание в карточку фильма (`full` view)**:
   * Отслеживание открытия карточки (`Lampa.Listener.follow('full', ...)`).
   * Добавление кнопки `<div class="full-start__button selector view--online-test">` со стилями Lampa рядом с кнопкой «Торренты».
3. **Меню выбора и воспроизведение**:
   * При нажатии на кнопку открывается меню выбора (`Lampa.Select.show`):
     * *Проверка плеера (Тестовый HLS поток 1080p/720p)* — моментальный запуск плеера.
     * *Поиск фильма / серии в базе* — асинхронный поиск по названию/ID.
   * Запуск плеера через `Lampa.Player.play({ url, title, quality, timeline })` и передача плейлиста серий через `Lampa.Player.playlist(...)`.
   * Информирование через `Lampa.Noty.show(...)` об этапах поиска.

### Б. Публикация на GitHub
1. Инициализация локального репозитория `git init` в `C:\Users\root\project\ForLampa`.
2. Создание коммита с `plugin.js` и `README.md`.
3. Создание удаленного репозитория на GitHub через утилиту `gh repo create MaxYtre/lampa-online-plugin --public`.
4. Включение GitHub Pages (ветка `main` / `master`) либо предоставление URL через CDN jsDelivr (`https://cdn.jsdelivr.net/gh/MaxYtre/lampa-online-plugin@main/plugin.js`), который автоматически кеширует и отдает файлы с правильными CORS-заголовками.

## 4. План проверки (Verification Plan)

### Автоматическая проверка
1. Проверка синтаксиса JavaScript через Node.js: `node --check plugin.js`.
2. Проверка доступности URL скрипта по HTTPS (статус 200 OK и корректный заголовок `content-type: application/javascript` или `text/plain`).

### Ручная проверка в Lampa
1. Открыть `http://lampa.mx/` в браузере или на ТВ.
2. Перейти в **Настройки** -> **Расширения** (или **Плагины**) -> **Добавить плагин**.
3. Вставить сгенерированную ссылку.
4. Перезагрузить Lampa -> открыть карточку любого фильма -> убедиться в появлении кнопки **«Онлайн»** и проверить запуск видеопотока.
